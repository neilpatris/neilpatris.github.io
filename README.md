# Personal Web Site

My portfolio as a Game Programmer.

## About

This is my portfolio website. The goal is to show my work as a Game Programmer :
my professional projects, my personal projects and my game jams.

It's a simple showcase website made with HTML, CSS and JavaScript, without framework.
The site is in French and in English.

## Structure

- `index.html` : the page
- `css/style.css` : the style
- `js/fr_projects.js` and `js/en_projects.js` : the projects data (FR / EN)
- `js/translations.js` : the texts of the page (FR / EN)
- `js/main.js` : language and menu
- `js/projects.js` : project cards, filters and project details
- `img/` : images and videos of the projects
